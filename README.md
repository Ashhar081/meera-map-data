# meera-map-data

Offline map data packages for personal navigation use.

## Contents

- Region map packages (`.pmtiles`) in the Protomaps basemap v4 schema.
- Region routing graphs (GraphHopper format) for offline turn-by-turn routing.
- The GitHub Actions workflow that builds these packages from public data sources.

No application source code and no personal data is published here.
